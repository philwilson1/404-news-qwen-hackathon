## Qwen Cloud Deployment

This project's AI inference runs entirely on **Alibaba Cloud's Qwen Cloud infrastructure** — no local or self-hosted models are used.

**How it's wired:**

- The backend (`Qwen-Agent/app.py`) uses the official `qwen-agent` framework, configured to call Qwen Cloud's OpenAI-compatible endpoint:
  ```
  https://token-plan.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1
  ```
- Every chat request — both the general "404 AI" assistant and the per-article contextual chat — is routed through this endpoint to a live Qwen model (`qwen3.6-flash`) hosted on Alibaba Cloud.
- The app is registered under an active **Qwen Cloud Standard Plan** subscription, with real token usage generated during development and testing.

**Proof of usage:**

See [`docs/qwen-cloud-usage-proof.png`](./docs/qwen-cloud-usage-proof.png) for a screenshot of the live Qwen Cloud subscription dashboard, showing the active plan and real API usage generated by this project.

**Architecture:**

```
User (Browser)
    │
    ▼
React Frontend (Vite + TypeScript)
    │  fetch → /chat
    ▼
Flask Backend (Qwen-Agent)
    │  qwen-agent SDK
    ▼
Qwen Cloud (Alibaba Cloud)
    │  qwen3.6-flash inference
    ▼
Streamed response → Frontend
```

Article data is scraped from live RSS feeds (`scraper.py`), stored in Supabase, and passed as context into the Qwen Cloud requests — meaning every AI response is grounded in real, current source articles rather than the model's own training data alone.
